# PCPT Data Processing Project

This project automates the conversion and integration of PCPT test data with Post-DC parameters.  
It includes:
- File cleanup
- CSV → Excel conversion
- Data normalization
- Merging with Post-DC parameters
- Summary diagnostics

## How to Run
1. Open `project.ipynb` in Google Colab or Jupyter Notebook.
2. Upload your PCPT CSV files that you wish you wish to convert to excel.
3. Run all cells to generate `Master_Combined.xlsx`.
